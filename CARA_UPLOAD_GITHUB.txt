CARA UPLOAD GITHUB PAGES

1. Ekstrak file ZIP.
2. Di GitHub, buat repo baru atau gunakan repo yang lama.
3. Upload seluruh isi folder, khususnya index.html, style.css, script.js, config.js, favicon.svg.
4. Masukkan 25 foto ke folder photos dengan nama foto-01.jpg s.d. foto-25.jpg.
5. Masukkan lagu MP3 berizin ke folder audio dengan nama lagu.mp3.
6. Buka Settings > Pages > Deploy from a branch > main > /(root) > Save.

EDIT TEKS, FOTO, LAGU, TANGGAL: buka config.js.
TIDAK PERLU REPLIT / NPM / BUILD.

CATATAN: GitHub Pages dari repository publik menampilkan foto secara publik.
